# Class agents & skills — attribution

Agent role files are adapted from the MIT-licensed
[agency-agents](https://github.com/msitarzewski/agency-agents) collection
(AgentLand Contributors), with Agile36 class skill sections added.

Companion skills were written for Agile36 AI Agents Academy, condensed from
common agent-skill patterns in MIT/Apache community packs (including ideas from
alirezarezvani/claude-skills, product-on-purpose/pm-skills, and
obra/superpowers). Skills are hosted locally for class use — students do not
need GitHub.
