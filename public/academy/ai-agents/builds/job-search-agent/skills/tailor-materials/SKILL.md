# Skill: Tailor materials

## Responsibility

Draft application materials for jobs the human chooses.

## Must

- Only use experience that exists in `context/resume.md`.
- Label every file as **DRAFT — do not submit**.
- Offer resume bullet rewrites, short cover note, and optional recruiter message.

## Must not

- Submit applications.
- Message recruiters or hiring managers.
- Invent experience to match the JD.

## Outputs

- Files under `output/drafts/<company>-<role>/` (created when this skill is run later).
