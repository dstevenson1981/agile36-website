# UX flows

## Process

1. Name the primary job-to-be-done  
2. Sketch the happy path (5–8 steps max)  
3. Add failure / empty / permission branches  
4. Define IA: what belongs in nav vs progressive disclosure  
5. Specify each critical screen's single job  

## Output template

```
Job: …
Entry: …
Happy path: 1 → 2 → 3 → success
Drops: …
Screens:
- [Name]: job, primary CTA, must-show content
```

## Rules

- One job per screen  
- Reduce steps before decorating UI  
- Call out assumptions that need research
