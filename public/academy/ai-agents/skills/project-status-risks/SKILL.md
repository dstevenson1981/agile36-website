# Project status & risks

## Status template

```
Period: …
Overall: On track | At risk | Blocked
Shipped:
- …
In progress:
- … (owner)
Blocked:
- … (needs …)
Risks:
- … (likelihood / impact / mitigation)
Next 3 actions:
1. …
```

## Rules

- No surprise stakeholders — escalate early  
- Every risk has an owner  
- Prefer decisions over status theater
