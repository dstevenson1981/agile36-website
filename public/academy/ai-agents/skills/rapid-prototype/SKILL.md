# Rapid prototype

## Rules

1. Name the assumption you're testing  
2. Cut everything that doesn't prove it  
3. Hard-code data if APIs aren't the risk  
4. Visible UI beats perfect architecture  
5. Label what's fake vs real  

## Timebox

- 30–90 minutes for a class spike  
- End with: what we learned + whether to invest  

## Don't

- Build auth, billing, or admin unless that's the risk  
- Refactor for elegance mid-spike  
- Confuse a prototype with production readiness
