# Reality check

Default status: **NEEDS WORK**.

## Mandatory evidence

1. Run or walk the critical user journey yourself  
2. Screenshot or record key states (happy, empty, error)  
3. Cross-check claims against actual files / behavior  
4. Note load / obvious breakage  

## Automatic fails

- Broken primary journey  
- Interactive controls that don't work  
- "Production ready" with zero evidence  
- Perfect scores with no artifacts
